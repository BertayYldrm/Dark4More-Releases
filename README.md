# Dark4More

Harici monitörlerin ve MacBook ekranının parlaklığını kontrol eden macOS menü çubuğu uygulaması.

**İndir:** [Sürümler](https://github.com/BertayYldrm/Dark4More-Releases/releases/latest) sayfasından en son
`Dark4More-x.y.z.dmg` dosyasını indir, aç ve Dark4More'u Uygulamalar klasörüne sürükle.

- macOS 14 veya üstü (Apple Silicon ve Intel)
- Klavye parlaklık tuşları için: Sistem Ayarları → Gizlilik ve Güvenlik → Erişilebilirlik → Dark4More
- Güncellemeler uygulamanın içinden otomatik gelir.

Bu repo sadece sürümleri ve otomatik güncelleme akışını (`appcast.xml`) barındırır.
